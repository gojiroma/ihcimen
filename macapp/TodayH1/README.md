# TodayH1

「今日のページ」(ihcimen / Daily Notes)に、Cmdキー2回押しで素早くH1ブロックを書き込むだけのmacOSメニューバーアプリ。

Webアプリ本体([../../index.html](../../index.html))とはブラウザを介さず、同じ同期サーバー(`/api/pull`, `/api/push`)に対して直接 pull → 復号 → 今日のエントリの先頭にブロック挿入 → 暗号化 → push を行う、「もう1台の同期デバイス」として動作します。暗号方式・sync_idの導出・箇条書き入力の挙動は、すべてWebアプリの実装([../../index.html](../../index.html)の`deriveSyncId`/`deriveAesKey`/`applyMarkdownEditorKeydown`など)をそのまま踏襲しています。

## ビルド

Xcode不要、Command Line Toolsのみで動きます。

```bash
./build.sh
```

`TodayH1.app` がこのディレクトリに生成されます。`open TodayH1.app` で起動、あるいは `/Applications` にコピーしてください。

## 初回セットアップ

1. `TodayH1.app` を起動する(メニューバーに鉛筆アイコンが出ます)。
2. メニューバーアイコン → 「設定…」を開く。
3. Webアプリ側の「設定 > 同期」パネルで表示されているシード文字列をコピーし、「同期シード」欄に貼り付けて「保存」。
   - 同期が未設定の場合は、先にWebアプリ側で同期をオンにしてください。
   - API URLは `https://ihcimen.vercel.app` がデフォルトで入っています(別のデプロイ先を使っている場合のみ変更)。
4. 「アクセシビリティ設定を開く」からTodayH1を許可する(Cmd2回押しのホットキー検知に必要)。
5. どこからでも **Cmdキーを素早く2回** 押すと入力パネルが出ます。

## 使い方

- 入力パネルは `# ` から始まっており、見出しを入力してEnterで自動的に箇条書き(`- `)に入る、Webアプリの本文欄と同じ挙動です。
- `⌘Return` で保存、`Esc` でキャンセル。
- 保存すると、今日のページの先頭に新しいH1ブロックとして挿入されます(既存の内容はそのまま残ります)。
- オフライン時や同期エラー時は保存を保留し(`~/Library/Application Support/TodayH1/pending.json`)、次回の書き込み時や起動時に自動で再送します。

## 既知の制約

- 同時編集の競合(このアプリでの書き込み中に、ブラウザ側でも編集していた場合など)は、Webアプリ側の「同期で競合」ダイアログで解決する形になります(サーバー側は複数デバイスからの同時書き込みを last-write-wins + 競合検出で扱う既存の仕組みをそのまま使っています)。
- Alt+↑/↓ による行入れ替えなど、箇条書き入力に直接関係しない編集機能は移植していません。
