      メニュー

      マウス操作
      • 本文はクリックで編集モードに切り替わります。
      • 下段カレンダーはノブのクリックで開閉、上へドラッグで全画面表示になります(下へドラッグ/クリックで戻ります)。
      • 右のWeek pane・左の検索パネルは端のタブで開閉、ノブへのホバーで一時的にプレビューできます。
      • 目次・見出しのショートカット・バージョン履歴は、本文エリア右下/右上/左上のアイコンから利用できます。
      キーボードショートカット

      以下は本文の入力中や検索窓の入力中には反応しません。それ以外の場面でキーを押すと動作します。

      基本操作

      • ? : このメニューを表示
      • t : 今日の日付に移動
      • f : 検索パネルを開く

      日付移動

      • ← : 前の日に移動
      • → : 次の日に移動
      • ↑ : 1週間前に移動
      • ↓ : 1週間後に移動
      • Shift + ↑ : 4週間前に移動
      • Shift + ↓ : 4週間後に移動
      • [ : 前の年に移動
      • ] : 次の年に移動

      その他

      • Esc : このウィンドウ(や全画面カレンダー)を閉じる
      データのバックアップと復元
      • 「エクスポート」でメモ全体をJSONファイルとしてダウンロードできます。定期的に保存しておくことをおすすめします。
      • 別のブラウザや端末でJSONを読み込むには「インポート」からファイルを選択します。
      • タブのタイトルに表示されている括弧内の数値は、保存領域の使用率です。

      この端末とサーバー上のデータを削除して初期状態に戻します。先に自動でエクスポートします。

      同期とプライバシー
      同期

      メモはこの端末のブラウザにのみ保存されています。ブラウザのデータを消去したりリセットすると失われるため、「データのバックアップと復元」からのエクスポートで定期的に控えを取っておくと安心です。

      同期は有効です。

      別の端末に引き継ぐ(QRコード・シードを表示)

      シード:

      カメラのない端末には、6桁のコードでも引き継げます(10分間だけ有効)。

      別の端末のシードをQRコードで読み取るか、下に貼り付けてください。

      カメラがない場合は、相手の端末で発行した6桁コードでも引き継げます。

      同期の仕組み
      • 同期する内容は、送信前に端末上で暗号化されます。サーバーには読み取れない暗号文しか保存されません。
      • シードを紛失すると、それまでに同期していたデータは復号できなくなります(ただし各端末に残っているローカルの日誌そのものには影響しません)。
      • 7日間同期が行われなかったデータは、サーバー側から自動的に削除されます。削除された後にこの端末を開くと、ローカルに残っているデータから自動的に復元されます。その後は、本文を編集するたびに再びサーバーへ同期されます。
      ICSカレンダー

      外部のICS(iCalendar)カレンダーを読み込んで、下段カレンダーのセルに予定を表示します。複数登録でき、それぞれに色を割り当てられます。
