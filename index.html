    同期を使う場合、内容は端末上で暗号化されます。詳しくは ? またはメニューから。

      メニュー

      マウス操作
      • 本文クリック: 表示されている本文をクリックすると、編集モードになります。
      • 下段カレンダー: 画面下部のバーは選択中の日付を中心に横スクロールできます(ホイール操作でもShiftキー不要でスクロールできます)。日付にカーソルを合わせるとその日のメモを「チラ見」でき、クリックすると日付が固定されます。各セルの入力欄には本文とは別に簡易的な予定を書き込めます。中央のノブはクリックで開閉、上にドラッグするとカレンダーだけを全画面表示できます(下にドラッグ、またはクリックで戻ります)。
      • 右側のWeek pane: 画面右側は選択中の週を中心に縦スクロールできます。「YYYY-Week XX」にカーソルを合わせるとその週の月曜日のメモを「チラ見」でき、クリックすると移動が固定されます。各セルの入力欄には週単位の簡易メモを書き込めます。端の「週」タブをクリックすると折りたたみ/展開できます。
      • 左側の検索パネル: 画面左端の「検索」タブをクリックすると検索パネルが開きます。キーワードを入力すると、見出し(h1)単位で該当箇所が一覧表示されます。結果にカーソルを合わせるとその見出しへプレビュー移動し、クリックするとその日付に移動して見出し直後にカーソルが入ります。
      • 目次: 本文内に見出し(# で始まる行)があると、右下に目次が表示されます。項目にカーソルを合わせると、閲覧モードならその見出しへスクロール、編集モードならその位置へカーソルが移動します。
      • 見出しのショートカット: 閲覧モードで見出し(h1)を右クリックすると、本文エリア右上にショートカットを追加できます。カーソルを合わせるとその日の見出しへ移動します。×で削除できます。
      • バージョン履歴: 左上の時計アイコンから、その日の過去のバージョンをスライダーで遡って確認し、必要であれば上書きできます。
      キーボードショートカット

      以下は本文の入力中や検索窓の入力中には反応しません。それ以外の場面でキーを押すと動作します。

      基本操作

      • ? : このメニューを表示
      • t : 今日の日付に移動
      • f : 検索パネルを開く
      • o : バックアップデータを取り込む
      • b : バックアップデータをダウンロード
      • s : 同期設定を表示

      日付移動

      • ← : 前の日に移動
      • → : 次の日に移動
      • ↑ : 1週間前に移動
      • ↓ : 1週間後に移動
      • Shift + ↑ : 4週間前に移動
      • Shift + ↓ : 4週間後に移動
      • [ : 前の年に移動
      • ] : 次の年に移動

      その他

      • Esc : このウィンドウを閉じる
      データのバックアップと復元
      • 「バックアップを保存」でメモ全体をJSONファイルとしてダウンロードできます。定期的に保存しておくことをおすすめします。
      • 別のブラウザや端末でJSONを読み込むには、「バックアップを読み込む」からファイルを選択します。
      • タブのタイトルに表示されている括弧内の数値は、保存領域の使用率です。
      同期とプライバシー
      • 同期は初期状態では無効です。「同期設定」から「同期を有効にする」を押すと使えるようになります。
      • 同期する内容は、送信前に端末上で暗号化されます。サーバーには読み取れない暗号文しか保存されません。
      • 別の端末で同じデータを見るには、QRコードを読み取るか、シードの文字列を貼り付けて引き継いでください。シードを紛失すると、それまでに同期していたデータは復号できなくなります(ただし各端末に残っているローカルの日誌そのものには影響しません)。
      • 7日間同期が行われなかったデータは、サーバー側から自動的に削除されます。
