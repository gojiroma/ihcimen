    メニュー

    キーボードショートカット

    以下は本文の入力中や検索窓の入力中には反応しません。それ以外の場面でキーを押すと動作します。

    基本操作

    • ? : このメニューを表示
    • t : 今日の日付に移動
    • f : 検索パネルを開く

    日付移動

    • ← : 前の日に移動
    • → : 次の日に移動
    • ↑ : 1週間前に移動
    • ↓ : 1週間後に移動
    • Shift + ↑ : 4週間前に移動
    • Shift + ↓ : 4週間後に移動
    • [ : 前の年に移動
    • ] : 次の年に移動

    その他

    • Esc : このウィンドウ(や全画面カレンダー)を閉じる
    • Cmd/Ctrl + Enter : 編集中のメモ(新規・既存とも)を保存して、続けて別の話題を書き始める
